# Thiệp cưới Hoa Mộc Xanh — Starter

## Cấu trúc

- `index.html` — giao diện
- `style.css` — giao diện, responsive, animation
- `app.js` — logic
- `config.js` — toàn bộ dữ liệu cần thay
- `assets/images/` — ảnh
- `assets/music/` — nhạc

## Cách dùng

1. Mở `config.js`.
2. Đổi tên cô dâu/chú rể, ngày cưới, địa điểm, Google Maps.
3. Đặt ảnh vào `assets/images/`.
4. Đặt nhạc MP3 vào `assets/music/wedding.mp3`.
5. Mở `index.html` để kiểm tra.

Ảnh mặc định được tham chiếu:
- `cover.jpg`
- `groom.jpg`
- `bride.jpg`
- `gallery-01.jpg` ... `gallery-06.jpg`
- `final.jpg`
- `qr.jpg`

Bạn có thể thay bằng ảnh thật nhưng giữ nguyên tên file.

## Đưa lên GitHub + Cloudflare Pages

Upload toàn bộ thư mục lên GitHub, sau đó tạo Cloudflare Pages project và kết nối repository. Đây là website tĩnh nên không cần Node.js/backend để chạy bản cơ bản.

## Lưu ý

Bộ khung này là thiết kế riêng theo phong cách xanh lá/botanical thanh nhã, lấy cảm hứng từ bố cục thiệp cưới mẫu; không sao chép nguyên mã nguồn, hình ảnh hay tài nguyên của website mẫu.
